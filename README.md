# Portfolie

Min personlige portfolio-side.

## Struktur

- `content/` — indhold
- `public/` — statiske filer
- `scripts/` — hjælpescripts
- `index.html`, `404.html` — sider

## Kør

Se `package.json` og `scripts/` for de tilgængelige kommandoer.

## Bemærk

`node_modules/` og `.DS_Store` bør ikke være i git. Se `.gitignore`.
